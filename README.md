This is the source code for [Grok TiddlyWiki](https://groktiddlywiki.com/read),
a textbook that helps you build a deep, lasting understanding of and
proficiency with [TiddlyWiki](https://tiddlywiki.com) through a combination of
detailed explanations, practical exercises, and spaced-repetition reviews of
prompts called takeaways.

Issues are disabled on this repository – if you have a problem or suggestion,
please instead use the “send feedback” button on the specific section, exercise,
or takeaway within the wiki. This will give me much more context than I'd get
from a generic GitHub issue.


## AI use

All of the text, exercises, and takeaways in _Grok TiddlyWiki_ are 100%
human-written.

I have made some use of generative AI in editing and proofing _Grok TiddlyWiki_
In particular,
I’ve had Claude look for factual errors and do the exercises to look for mistakes.
When TiddlyWiki is updated and I go to make a new version of the book,
I ask it to read the changelogs and search the book for things that might need to change
(I also make my own list, and we compare notes).

I occasionally have Claude Code make changes to system tiddlers,
but for the most part I do these myself when I do new editions
as part of understanding the new features well enough to write about them.
